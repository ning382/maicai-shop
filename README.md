# 买菜清单 🛒

> 选好菜，照着买，不落下一样。

「买菜清单」是一款**纯前端本地应用**：先选几道想做的菜，应用按份数自动汇总食材（同名同单位自动累加），生成一份按分类分组、可逐项勾选的购物清单。所有数据只保存在本设备，无需注册登录，断网也能用。

详细使用说明见 [买菜清单-使用文档与介绍.md](./买菜清单-使用文档与介绍.md)。

## ✨ 功能特性

- **选菜即汇总**：按份数选菜，食材自动合并数量，每项标注「来自哪道菜」
- **食材金字塔分类**：内置营养金字塔分层（顶层少吃、底层多吃），支持自定义层序、颜色与左右分格
- **一周饮食规划**：7 天 × 4 餐（早/午/晚/加餐）排菜，一键把整周规划生成购物清单
- **价格与预估总价**：条目可设单价与计价单位，清单自动计算预估总计（食材 + 其他分项）
- **清单交互**：逐项勾选、进度条、复制清单（只复制未勾选项）、完成购物一键清空
- **备份与迁移**：一键导出/导入 JSON，换手机不丢数据
- **双形态安装**：PWA 可安装到手机桌面，也提供安卓 APK
- **内置营养数据集**：预置 28 道菜品（附 Food Compass 评分备注）、102 条食材条目与一整周 28 餐规划

## 📱 五大页面

| 页面 | 作用 |
| --- | --- |
| 清单 | 勾选已买、看进度、复制清单、预估总计、完成购物 |
| 选菜 | 两级分类挑菜品/条目、调份数、跨分类搜索 |
| 规划 | 一周排菜，整周规划一键生成清单 |
| 菜品库 | 管理菜品、条目、金字塔分类、菜品子分类 |
| 设置 | 备份/导入/恢复示例/清空数据、安装帮助 |

## 🚀 快速开始

**电脑**：直接用浏览器打开 `index.html` 即可。

**安卓**：下载 [dist/maicai.apk](./dist) 安装（APK 不入库，按下方构建命令自行生成）。

**iPhone**：Safari 打开应用网址 → 分享 → 「添加到主屏幕」，即以独立 App 形式运行。

## 🔒 数据与隐私

- 所有数据保存在本设备浏览器的 localStorage 中，**不上传任何服务器**
- 卸载应用或清理浏览器数据会丢失数据，建议定期在「设置 → 导出备份」下载 JSON
- 换机迁移：旧设备导出备份 → 新设备「导入备份」选择该文件，完整恢复（含一周规划）

## 🛠 技术栈

- **前端**：原生 HTML + CSS + JavaScript，单文件 `app.js`，零框架、零外部依赖
- **离线**：Service Worker 预缓存全部资源，Web App Manifest 支持 PWA 安装
- **安卓打包**：Capacitor 7（appId `com.maicai.shop`）

## 📦 构建与发版

```bash
node tools/sync-www.js                  # 同步 web 资源到 www/
npx cap sync android                    # 同步到安卓工程
gradlew.bat -p android assembleDebug    # 构建 APK
# 产物：android/app/build/outputs/apk/debug/app-debug.apk → 复制到 dist/
```

> 注意：改动功能后需同步升级 `sw.js` 中的缓存版本号，否则已安装用户拿不到新资源。

## 📂 项目结构

```
shop/
├── index.html              # 入口页面（5 个视图 + 弹层容器）
├── app.js                  # 全部业务逻辑（状态、渲染、弹层编辑器）

├── sw.js                   # Service Worker 离线缓存
├── manifest.webmanifest    # PWA 清单
├── icons/                  # 应用图标
├── dist/                   # 发布产物（APK、数据备份 JSON）
├── android/                # Capacitor 安卓原生工程
└── tools/                  # 辅助脚本（资源同步、图标生成、数据导入页、测试脚本）
```
